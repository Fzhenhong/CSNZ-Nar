## CSNZ-Nar 解包打包工具 v1.0.0

首个正式版本。一体化的 NAR 归档解包 / 打包工具，解决旧工具「大文件内存不足、解压中断」的问题。

### 下载

| 文件 | 说明 |
|---|---|
| `CSNZ-Nar.exe` | 图形界面，双击即用 |
| `nar.exe` | 命令行版本 |

单文件可执行，**无需安装 .NET 运行时**。

### 主要特性

- **流式处理**：内存占用与归档大小无关，实测 2 GB 归档峰值内存 42 MB
- **多线程解包**：按条目并行，读盘随机访问、写盘顺序
- **解包打包一体**：同一界面 / 同一命令族
- **零参数自动还原**：解包时写出 `.nar-info.json` 记录路径、存储方式、模型版本、
  数据区偏移与目录表序号，打包时自动套用，无需人工指定任何参数
- **模型自动加解密**：`.mdl` 的 ICE 加解密，可还原原始 20/21 号密钥
- **容错**：单文件失败不影响其余，最后汇总报告；写入完成前不覆盖目标文件

### 兼容性验证

用官方 `CSOToolLib` 验证本工具生成的归档：

| 检查项 | 结果 |
|---|---|
| 原厂库打开 | 10996 条全部成功 |
| 原厂库全量解出 | 成功 10996 / 失败 0 |
| 原厂 `Verify()` CRC 校验 | 通过 10996 / 失败 0 |
| 解出内容 MD5 逐条比对 | 10996/10996 完全一致 |

`cstrike.nar`（2 GB / 10853 项）解包后原样打包，产物与原文件 **SHA-256 完全相同**。

### 已知限制

- 官方归档中的数据区碎片（不属于任何条目）无法还原，重打包后体积会变小，
  但所有条目内容与客户端行为完全一致
- 单个条目大小受 NAR 目录表 int32 字段限制（最大 2 GB）
