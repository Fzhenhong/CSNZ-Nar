## CSNZ-Nar 解包打包工具 v1.1.1

修复打包启动延迟。

### 下载

| 文件 | 说明 |
|---|---|
| `CSNZ-Nar.exe` | 图形界面，双击即用 |
| `nar.exe` | 命令行版本 |

### 修复的问题

点击「开始打包」后，进度条会停顿数秒才开始滚动。原因有两个：

1. **准备阶段无进度反馈**：扫描目录、读取清单、统计文件的开销没有上报，
   界面上表现为「点了没反应」
2. **句柄突发阻塞**：分批时一次性打开全部上万文件句柄（实测 5000 个就要 118 ms），
   造成明显停顿

### 现在的表现

```
[  8 ms]  正在扫描目录...
[ 95 ms]  正在枚举文件...
[128 ms]  共 10853 个文件，准备打包...
[214 ms]  第一个文件开始处理
```

- 首次反馈 **8 毫秒**（原来要等数秒）
- 连续 3 次运行均无超过 250 ms 的停顿

### 改动内容

- 准备阶段分三次上报具体动作
- 批次增加文件数上限（默认 CPU 核心数 × 4），避免句柄突发
- 批内文件改为并行打开

### 正确性

线程数 1/2/3/5/8/16/32 打包产物 SHA-256 全部一致；解包 10853 项 CRC 全通过。
