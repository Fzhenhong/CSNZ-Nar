## CSNZ-Nar 解包打包工具 v1.1.4

**重要修复：打包时条目大小记录错误，会导致文件内容被截断。请尽快升级。**

### 下载

| 文件 | 说明 |
|---|---|
| `CSNZ-Nar.exe` | 图形界面，双击即用 |
| `nar.exe` | 命令行版本 |

### 修复的问题

用 v1.1.0 ~ v1.1.3 打包时，NAR 目录表中的**原始大小字段写成了压缩后大小**，
导致客户端解包时只能还原出部分内容。

典型表现：替换 `csnz.ico` 后重新打包，客户端标题图标不显示。

### 根本原因

`NarLzCodec.Compress` 的返回值语义不一致——函数内部返回的是**压缩输出的字节数**，
而调用方 `NarBuilder` 把它当作**原始大小**写进了目录表：

```
目录表 size = 213      （压缩后大小，错误）
实际原始大小 = 2046    （被截断丢失）
```

客户端按 size=213 解包，只拿到前 213 字节，图标文件结构不完整，因此显示不出。

### 影响范围

- 仅影响 **v1.1.0 ~ v1.1.3** 打包生成的归档
- v1.0.0 不受影响（该版本压缩路径实现不同）
- 解包功能一直正常，问题只在打包

### 现在的表现

```
源图标 2046 字节 → 打包 → 解包 → 2046 字节，哈希完全一致，图标可正常加载
```

### 验证

- 15 种边界尺寸（0 / 1 / 17 / 2046 / 65535 / 1 MB / 1 MB+1 等）逐字节一致
- 2 GB 归档解包→打包仍 **SHA-256 完全相同**
- 生成归档经原厂 CSOToolLib 校验通过

### 顺带说明

如果你替换的图标本身是损坏的（例如多尺寸 ICO 被截断，声明 6 个图标但数据不全），
Windows 同样无法加载。正常的单尺寸 48×48 ICO 文件约 2~10 KB。
